================================================================================
                КАК ПОЛУЧИТЬ CREDENTIALS ДЛЯ YOUTUBE API
================================================================================

Эта инструкция нужна для каждого аккаунта YouTube, на который будут
выкладываться видео. Для каждого аккаунта - отдельный проект в Google Cloud.

--------------------------------------------------------------------------------
Шаг 1: Создай проект в Google Cloud
--------------------------------------------------------------------------------

1. Иди на сайт: https://console.cloud.google.com
2. Нажми "Select project" → "New project"
3. Назови проект: YouTube Uploads (или любое имя)
4. Нажми "Create"
5. В выпадающем списке выбери созданный проект

--------------------------------------------------------------------------------
Шаг 2: Включи YouTube Data API v3
--------------------------------------------------------------------------------

1. Слева в меню: APIs & Services → Library
2. В поиске найди "YouTube Data API v3"
3. Нажми на него → нажми "Enable"

--------------------------------------------------------------------------------
Шаг 3: Создай OAuth Credentials
--------------------------------------------------------------------------------

1. Слева в меню: APIs & Services → Credentials
2. Нажми "Create credentials" → "OAuth client ID"
3. Если появится экран "Configure Consent Screen":
   - User Type: Выбери EXTERNAL (не Internal! Internal работает только для Google Workspace)
   - Нажми "Create"
   - Заполни обязательные поля:
     * App name: YouTube Bot
     * User support email: твой email
     * App logo: можно пропустить
     * Developer contact email: твой email
   - Нажми "Save and continue"
   - На странице "Scopes" → нажми "Save and continue" (не добавляй scope вручную)
   - На странице "Test users" → нажми "Add users" → добавь свой email (europapa019@gmail.com)
     ВАЖНО: Пока приложение в режиме "Testing", только добавленные тест-юзеры могут авторизоваться!
   - Нажми "Save and continue"
   - Вернись на Dashboard → нажми "PUBLISH APP" (иначе токен протухает через 7 дней)
4. Теперь снова: APIs & Services → Credentials → "Create credentials" → "OAuth client ID"
5. "Application type": Desktop app (не Web application! Desktop app не требует redirect URI)
6. "Name": YouTube Bot
7. Нажми "Create"
   Примечание: InstalledAppFlow.run_local_server() запускает сервер на случайном порту,
   поэтому Web application с фиксированным redirect URI не работает (ошибка redirect_uri_mismatch).
   Desktop app использует loopback redirect и работает корректно.

--------------------------------------------------------------------------------
Шаг 4: Скачай client_secret.json
--------------------------------------------------------------------------------

1. Нажми кнопку "Download JSON"
2. Сохрани файл на компьютер

--------------------------------------------------------------------------------
Шаг 5: Загрузи в бота
--------------------------------------------------------------------------------

1. Запусти бота (python -m uvicorn app.main:app --reload)
2. Открой в браузере http://localhost:8000
3. Перейди на вкладку "Интеграция"
4. В секции "Загрузить готовые credentials":
   - Введи email аккаунта YouTube
   - Нажми "Выбрать файл" и выбери скачанный client_secret.json
   - Нажми "Добавить аккаунт"

--------------------------------------------------------------------------------
Шаг 6: Авторизуй аккаунт
--------------------------------------------------------------------------------

1. В той же вкладке "Интеграция"
2. Нажми "Авторизовать аккаунты через YouTube API"
3. Откроется браузер с запросом доступа
4. Войди в нужный аккаунт Google
5. Нажми "Разрешить"
6. Токен сохранится автоматически в папку tokens/

--------------------------------------------------------------------------------
ПРИМЕЧАНИЯ
--------------------------------------------------------------------------------

ВАЖНО: Для каждого аккаунта YouTube нужен СВОЙ отдельный проект в Google Cloud
       и свой client_secret.json. Нельзя использовать одни credentials для
       разные аккаунтов.

       Пример:
       - Аккаунт1@gmail.com → Проект1 → client_secret1.json
       - Аккаунт2@gmail.com → Проект2 → client_secret2.json
       - и т.д.

--------------------------------------------------------------------------------
ЧАСТЫЕ ОШИБКИ И ИХ РЕШЕНИЯ
--------------------------------------------------------------------------------

1. Ошибка: "redirect_uri_mismatch"
   Причина: Создан OAuth client типа "Web application"
   Решение: Удали его и создай заново тип "Desktop app"
            (InstalledAppFlow использует случайный порт, Web app не подходит)

2. Ошибка: "Приложение не прошло проверку" (access_denied, 403)
   Причина: Email не добавлен в Test users
   Решение: APIs & Services → OAuth consent screen → Test users → Add users
            → добавь свой email → Save

3. Ошибка: "Authorization failed" (токен протух)
   Причина: Приложение в режиме "Testing" — токен живёт 7 дней
   Решение: OAuth consent screen → Dashboard → нажми "PUBLISH APP"
            После публикации токен не протухает

4. Ошибка: "Authorization failed" (после длительного перерыва)
   Причина: Refresh token истёк или отозван
   Решение: Удали файл tokens/token_<email>.pickle и авторизуйся заново

5. Браузер показывает "The authentication flow has completed. You may close this window."
   Это НОРМАЛЬНО — значит авторизация прошла успешно!
   Можешь закрыть вкладку и вернуться в бота.

--------------------------------------------------------------------------------
КАК ОПУБЛИКОВАТЬ ПРИЛОЖЕНИЕ (PUBLISH APP)
--------------------------------------------------------------------------------

Пока приложение в режиме "Testing":
- Токен протухает каждые 7 дней
- Авторизоваться могут только добавленные Test users
- Google показывает предупреждение "Это приложение не проверено"

Чтобы опубликовать:
1. APIs & Services → OAuth consent screen → Dashboard
2. Нажми "PUBLISH APP"
3. Подтверди

ВАЖНО: Для публикации Google может потребовать верификацию приложения.
Если у тебя меньше 100 авторизованных пользователей — верификация не нужна,
просто нажми PUBLISH и подтверди.

После публикации:
- Токен не протухает каждые 7 дней
- Любой пользователь может авторизоваться (если не добавлены ограничения)
- Предупреждение "не проверено" не показывается

--------------------------------------------------------------------------------
КАК ДОБАВИТЬ НОВЫЙ АККАУНТ
--------------------------------------------------------------------------------

1. Создай новый проект в Google Cloud (Шаг 1)
2. Включи YouTube Data API v3 (Шаг 2)
3. Настрой OAuth consent screen (Шаг 3):
   - External
   - Добавь email нового аккаунта в Test users
   - PUBLISH APP
4. Создай OAuth client ID типа Desktop app (Шаг 3)
5. Скачай client_secret.json (Шаг 4)
6. Загрузи в бота через вкладку "Интеграция" (Шаг 5)
7. Авторизуй аккаунт (Шаг 6)

--------------------------------------------------------------------------------
РАЗМЕЩЕНИЕ НА СЕРВЕРЕ
--------------------------------------------------------------------------------

Если будешь выкладывать бота на сервер с доменом:
- OAuth flow через InstalledAppFlow открывает браузер на сервере
- На сервере без GUI это не работает
- Нужно заменить InstalledAppFlow на авторизацию через redirect URI

Для сервера нужно:
1. Создать OAuth client типа "Web application"
2. Добавить redirect URI: https://твой-домен.com/oauth2callback
3. Изменить код youtube_api.py для использования веб-флоу

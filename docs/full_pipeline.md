# Полный пайплайн смарт-отбора

## Как получаются сегменты

```
Whisper (транскрипция)
       ↓
[{start:0.5, end:1.2, text:"Привет"},
 {start:1.3, end:2.0, text:"мир"},
 {start:5.0, end:5.8, text:"Это видео"}]
       ↓
_build_phrases() — склейка по паузам (< 1с = одна фраза)
       ↓
[{start:0.5, end:2.0, words:2, duration:1.5, full_text:"Привет мир"},
 {start:5.0, end:5.8, words:1, duration:0.8, full_text:"Это видео"}]
```

---

## Параметры

| Параметр | Откуда | Значение |
|----------|--------|----------|
| `short_length` | UI (по умолч. 45с) | Длина одного шортса |
| `shorts_count` | UI (по умолч. 5) | Сколько нужно шортсов |
| `step` | `short_length // 2` | Шаг скользящего окна |
| `parts` | `max(min(shorts_count, 200), 20)` | Количество частей (для parts/hybrid) |
| `part_len` | `duration / parts` | Длина одной части |
| `max_analyze` | `min(part_len, 1200)` | Максимум транскрипции на часть |
| `top_k` | 3 (hybrid) / 1 (parts) | Сколько кандидатов из части |

---

## Два движка скоринга

### Движок А — простая формула (без ИИ)
**Когда:** видео ≤ 7200с (2ч) **или** part_len ≤ 7200с

**Входные данные:** только текст

**Параметры (6 штук, все из Whisper):**

```
density         = total_words / short_length
  сколько слов приходится на секунду окна
  Пример: 45 слов за 45с → density = 1.0
  Диапазон: 0.0 — 10.0+

speech_ratio    = speech_duration / short_length
  доля времени окна, занятая речью (не тишиной)
  Пример: речь 30с из 45с → 0.67
  Диапазон: 0.0 — 1.0

avg_phrase_len  = total_words / count
  средняя длина одной фразы в словах
  Пример: 45 слов / 10 фраз → 4.5
  Диапазон: 1 — 50+

unique_ratio    = unique_words / total_words
  насколько разнообразный словарь (1 = все слова разные)
  Пример: "Привет привет привет" → 1/3 = 0.33
  Диапазон: 0.0 — 1.0

emotion_boost   = (! × 3) + (? × 2)
  эмоциональная насыщенность через знаки препинания
  Пример: "Невероятно! Ты серьёзно?" → 3 + 2 = 5
  Диапазон: 0 — ∞ (нормируется до 1 при ≥10)

pacing_var      = std(phrase_lengths) / mean(phrase_lengths)
  вариативность длины фраз (0 = монотонно, 1+ = динамично)
  Пример: фразы [3, 7, 2, 8] → mean=5, std≈2.5 → 0.5
  Диапазон: 0.0 — 2.0+
```

**Формула:**

```
Score = ──────────────────────────────────────────────────────
        min(density / 5, 1)         × 25     (макс 25 баллов)
      + min(speech_ratio, 1)        × 25     (макс 25 баллов)
      + min(avg_phrase_len / 20, 1) × 15     (макс 15 баллов)
      + unique_ratio                × 15     (макс 15 баллов)
      + min(emotion_boost / 10, 1)  × 10     (макс 10 баллов)
      + min(pacing_var, 1)          × 10     (макс 10 баллов)
        ─────────────────────────────────────
        max 100 баллов
```

**Визуально — вес каждой метрики:**

```
▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄  25  density
▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄  25  speech_ratio
▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄           15  avg_phrase_len
▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄           15  unique_ratio
▄▄▄▄▄▄▄▄▄▄                10  emotion_boost
▄▄▄▄▄▄▄▄▄▄                10  pacing_var
```

### Движок Б — InterestNet (PyTorch)
**Когда:** видео > 7200с (2ч)

**Входные данные:** текст + аудио + визуал

**Параметры (14 штук):**

```
Текст (7):
  total_words       — количество слов
  density           — total_words / short_length
  speech_ratio      — речь / окно
  avg_phrase_len    — слов на фразу
  unique_ratio      — уникальных / всего слов
  emotion_boost     — !×3 + ?×2
  pacing_var        — std/mean длин фраз

Аудио (4) — извлекается ffmpeg один раз на всё видео:
  energy_mean       — средняя громкость (0.0 тихо — 1.0 громко)
  energy_peak       — пиковая громкость (максимальный всплеск)
  energy_variance   — разброс громкости (0 монотонно — >0 динамично)
  silence_ratio     — доля тишины (0 всё шумит — 1 полная тишина)

Визуал (3) — извлекается ffmpeg один раз на всё видео (5fps):
  scene_changes     — количество смен сцен (0 статично — 10+ много монтажа)
  face_count_avg    — среднее лиц на кадр (0 никого — 5+ толпа)
  motion_intensity  — интенсивность движения (0 стоп-кадр — 1+ активно)
```

**Архитектура сети:**

```
Input(14) → Linear(14→32) → ReLU → Linear(32→16) → ReLU → Linear(16→1) → Sigmoid
    ↓
Выход: nn_score [0.0 — 1.0]
```

**Обучение (20 эпох, прямо на текущем видео):**

```
1. Берём все окна видео (N штук)
2. Считаем heuristic_score (запасная формула)
3. Топ-20% по heuristic → метка 1 (интересно)
   Остальные 80% → метка 0 (неинтересно)
4. 20 эпох: подаём 14 признаков → сеть → сравниваем с меткой → подкручиваем веса
5. После обучения: каждый кандидат получает nn_score
```

**Опционально — LLM дооценка (если есть OpenAI/Groq ключ):**

```
Топ-10 кандидатов → GPT оценивает текст → llm_score 0..1
Итог: final_score = 0.6 × nn_score + 0.4 × llm_score
```

## Скользящее окно (одинаково для обоих движков)

```
Ширина окна = short_length (напр. 45с)
Шаг = short_length // 2 (напр. 22с)

Для short_length=45с, duration=3600с:
  step = 45 // 2 = 22с
  окон = 3600 // 22 ≈ 163 окна

Каждое окно: [start, start + short_length]

Визуально для duration=100с, short_length=30с, step=15с:

  0──────30     ← окно 0
     15──────45 ← окно 1
        30──────60 ← окно 2
           45──────75 ← окно 3
              60──────90 ← окно 4
                 75─────105 ← окно 5 (105 > 100 → отбрасывается)
```

---

## Как это работает в каждом режиме

### `off`

```
Никакого скоринга. Просто:
segment_len = duration / shorts_count
for i in range(shorts_count):
    segments.append({start: i×segment_len, end: (i+1)×segment_len})
```

Сложность: O(1)

### `global` — Топ

```
1. Делим видео на parts (для транскрипции, части могут перекрываться)
   parts = max(min(shorts_count, 200), 20)

2. Каждую часть транскрибируем Whisper

3. Выбираем движок:
   duration > 7200с → InterestNet (14 признаков)
   иначе           → простая формула (6 метрик)

4. Запускаем скользящее окно по ВСЕЙ длительности (0 — duration)
   Для каждого окна считаем score

5. Все окна → сортировка по score (убывание)

6. Отбор непересекающихся:
   best = []
   for окно in отсортированные:
       if не пересекается ни с кем в best:
           best.append(окно)
       if len(best) == shorts_count:
           break

7. Если набрали меньше → второй проход
```

**Пример для видео 3600с, short_length=45с, shorts_count=3:**

```
Шаг = 22с, окон ≈ 163

Сортировка по score:
  1.  800—845с  score 92  → берём
  2.  822—867с  score 90  ✗ пересекается с 1
  3.  100—145с  score 88  → берём
  4. 2900—2945с score 85  → берём
  5.  845—890с  score 84  ✗ пересекается с 1
  ...

Результат: [800—845, 100—145, 2900—2945]
```

---

### `parts` — Сетка

```
1. parts = max(min(shorts_count, 200), 20)
   part_len = duration / parts

2. Для КАЖДОЙ части p:
   start = p × part_len
   end   = min(start + max_analyze, duration)
   Whisper(start, end) → part_segments

   Движок: так как part_len < 7200с, ВСЕГДА простая формула
   (даже если всё видео > 2ч)

   best = _find_best_segments(part_len, short_length, 1, part_segments)
   → 1 лучший непересекающийся из этой части

3. Если после всех частей набрали < shorts_count:
   добивка из all_segments через глобальный _find_best_segments

4. segments = results[:shorts_count]
```

**Пример для видео 3600с, shorts_count=5, short_length=45с:**

```
parts = max(min(5, 200), 20) = 20
part_len = 3600/20 = 180с

Часть 0 (0—180с):     _find_best(180,45,1) → [45—90с]    score 62
Часть 1 (180—360с):   _find_best(180,45,1) → [200—245с]   score 78
Часть 2 (360—540с):   _find_best(180,45,1) → [400—445с]   score 45
Часть 3 (540—720с):   _find_best(180,45,1) → [600—645с]   score 91
Часть 4 (720—900с):   _find_best(180,45,1) → [750—795с]   score 33

Результат: [45—90, 200—245, 400—445, 600—645, 750—795]
Каждый — из своей части, остальные 15 частей не сканируются
```

---

### `hybrid` — Гибрид

```
1. parts = max(min(shorts_count, 200), 20)
   part_len = duration / parts

2. Для video_path и длительности > 7200с:
   - ffmpeg дёргает аудио + визуал 1 раз, кеширует
   - Whisper транскрибирует все части
   - InterestNet обучается на ВСЕХ окнах всего видео (как global)
   - Каждое окно получает nn_score

   Для video_path и длительности ≤ 7200с:
   - Только Whisper
   - Простая формула (как parts, но top_k=3)

3. Из КАЖДОЙ части забираем топ-3 непересекающихся:
   best3 = _find_best_segments(part_len, short_length, 3, part_segments)

4. Все топ-3 со всех частей → общий пул:
   candidates = parts × 3

5. Сортировка candidates по score/nn_score (убывание)

6. Отбор непересекающихся (как в global)

7. Если набрали < shorts_count → добивка из all_segments
```

**Пример для видео 3600с, shorts_count=3, short_length=45с:**

```
parts = max(min(3, 200), 20) = 20
part_len = 180с
top_k = 3
candidates = 20 × 3 = 60

Из каждой части по 3 непересекающихся:
  Часть 0:  [30—75с, 0—45с, 90—135с]     scores [78, 62, 55]
  Часть 1:  [200—245с, 260—305с, 310—355с] scores [91, 72, 68]
  Часть 2:  [400—445с, 370—415с, 430—475с] scores [45, 40, 38]
  ... все 20 частей

Все 60 кандидатов → сортировка по score:

  1.  200—245с  score 91 ← берём
  2.  30—75с    score 78 ← берём (не пересекается с 200)
  3.  260—305с  score 72 ← берём (не пересекается)

Результат: [200—245с, 30—75с, 260—305с] — равномерно по видео + высокий скор
```

## Сравнение режимов

Режим | Скользящих окон | Вызовов Whisper | Использует InterestNet | Покрытие | Качество
------|----------------|----------------|----------------------|----------|---------
off | 0 | 0 | Нет | Равномерное | Нет
global | duration/step | parts | Да (>2ч) | Неравномерное | Максимальное
parts | parts × (part_len/step) | parts | Нет (всегда) | Равномерное | Среднее
hybrid | duration/step | parts | Да (>2ч) | Хорошее | Высокое

## Сложность (Big O) для каждого этапа

```
N = duration / step              (количество окон)
P = parts                        (количество частей)
M = количество Whisper-сегментов
K = shorts_count                 (сколько нужно шортсов)
T = количество кандидатов       (P × top_k для hybrid, N для global)
```

### _build_phrases
```
O(M) — проход по всем сегментам один раз
```

### Скользящее окно + скоринг (простая формула)
```
O(N × M) — каждое окно просматривает фразы
На практике N × M ≤ 1 млн для 10ч видео — мгновенно
```

### extract_features_for_windows (InterestNet)
```
O(N) — 2 ffmpeg вызова (аудио + видео), затем нарезка по индексам

ffmpeg аудио: O(duration) — читает звук целиком
ffmpeg видео: O(duration × fps) — кадры 5fps
```

### Обучение InterestNet
```
O(epochs × N × hidden_size)
20 × N × 1025 весов — для 1000 окон ~20 млн операций (~0.1с на GPU)
```

### Сортировка кандидатов
```
O(T log T) — T = 60..600 для hybrid, 163+ для global
```

### Отбор непересекающихся
```
O(T × K) — проход по кандидатам, проверка с уже выбранными
В худшем случае O(N²), но break при K = shorts_count
```

**Итоговая сложность по режимам:**

| Режим | Сложность |
|-------|-----------|
| off | O(1) |
| global (без ИИ) | O(N × M + N log N + N × K) |
| global (с ИИ) | O(P × M + ffmpeg(duration) + epochs×N + N log N + N×K) |
| parts | O(P × (N_p × M_p + N_p log N_p) + N × M) |
| hybrid (без ИИ) | O(N × M + P × (N_p × M_p + N_p log N_p) + T log T + T × K) |
| hybrid (с ИИ) | O(P × M + ffmpeg(duration) + epochs×N + T log T + T × K) |

где `N_p = part_len / step`, `M_p ≈ M / P`.

### Узкое место

```
Все режимы: Whisper-транскрипция (секунды на каждую часть)
  └ 20 частей × 5-10с = 1-2 минуты

Только >2ч: ffmpeg аудио + кадры (ещё 10-30с)
  └ Но это 1 раз, не на каждую часть

Скоринг, сортировка, отбор: < 0.1с на любое видео
```

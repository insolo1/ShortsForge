# Смарт-отбор (Smart Selection)

Система интеллектуального выбора лучших фрагментов из длинного видео для нарезки shorts.

## Общий принцип

Видео делится на **N частей** (N = max(20, min(shorts_count, 200))).  
Каждая часть транскрибируется Whisper (модель `base`) — анализируется до 1200 секунд на часть.  
Далее в дело вступает скоринговая формула, оценивающая каждый сегмент по 6 критериям (0–100 баллов):

| Критерий         | Вес | Что измеряет |
|------------------|-----|-------------|
| Плотность текста | 25% | `min(длительность_сегмента / 5, 1) × 25` — короткие энергичные фразы |
| Речь vs тишина   | 25% | `min(ratio_речи, 1) × 25` — чем больше речи в сегменте, тем лучше |
| Длина фразы      | 15% | `min(слов / 20, 1) × 15` — не слишком короткая, не слишком длинная |
| Разнообразие     | 15% | Уникальные слова / всего слов — высокое разнообразие = информативнее |
| Эмоции           | 10% | `!` × 3 балла, `?` × 2 балла — восклицания и вопросы привлекают внимание |
| Темп речи        | 10% | Вариативность скорости речи — динамичные перепады интереснее монотона |

Сегменты с наибольшим баллом становятся кандидатами на финальные shorts.

## Режимы

### `off` — Выкл

Простое деление видео подряд на `shorts_count` равных частей.  
Без транскрипции, без анализа. Максимально быстро, но без гарантии качества.

**Когда использовать:** тестовые прогоны, короткие видео (до 5 мин), или когда нужно покрыть всё видео равномерно без приоритетов.

---

### `global` — Топ (глобальный рейтинг)

Все Wшер-сегменты со **всего видео** собираются в один пул.  
Из этого пула `_find_best_segments` выбирает топ-N непересекающихся фрагментов с лучшими оценками.

**Плюсы:** каждый short — объективно лучший кусок во всём видео.  
**Минусы:** лучшие моменты могут сгрудиться в одном месте (например, первые 30 секунд), а остальное видео останется незатронутым.

**Когда использовать:** видео с одним ярким блоком (интервью, лекция, обзор), где нужно вытащить максимум качества из любого места.

---

### `parts` — Сетка (лучший из каждой части)

Видео делится на **shorts_count** частей. В каждой части находится **один** лучший сегмент.  
Если не хватает до `shorts_count`, добирается из глобального пула оставшихся сегментов.

**Плюсы:** гарантированное равномерное покрытие всего видео — каждый short из своей части.  
**Минусы:** локальный «лучший» может быть слабее глобального — некоторые части могут быть неинтересными.

**Когда использовать:** длинные видео (лекции, стримы, записи эфиров) — нужно показать, что происходит на всём протяжении.

---

### `hybrid` — Гибрид (сетка + переранжирование)

Как и в `parts`, видео делится на части. Но из каждой части берётся **топ-3** кандидата (а не 1).  
После сбора всех кандидатов со всего видео выполняется глобальная сортировка по баллам, и выбираются топ-N непересекающихся.

**Плюсы:** сочетает равномерное покрытие `parts` с качественным отбором `global`.  
**Минусы:** чуть больше вычислений (3 кандидата на часть вместо 1).

**Когда использовать:** универсальный режим по умолчанию — подходит для большинства сценариев.

## Сравнение

| Режим   | Покрытие | Качество | Скорость |
|---------|----------|----------|----------|
| off     | равномерное | нет     | ⚡ быстрый |
| global  | неравномерное | ⭐⭐⭐ | 🐢 медленный |
| parts   | равномерное | ⭐⭐ | 🐢 медленный |
| hybrid  | хорошее | ⭐⭐⭐ | 🐢 медленный (+ немного) |

*Медленный* ≈ 1–5 минут на каждый час видео (зависит от размера Whisper-модели и GPU/CPU).

## Скоринг (детали)

Функция `_find_best_segments` в `processor.py`:

1. Получает список Whisper-сегментов с текстом, start/end.
2. Скользящим окном размера `short_length` (с шагом 2с) собирает группы сегментов.
3. Для каждой группы считает 6 метрик и сворачивает в общий балл.
4. Сортируем окна по баллу, отбираем непересекающиеся (с зазором 1с).
5. Возвращаем топ `count` штук.

Для режимов `parts` и `hybrid` функция вызывается один раз на часть (с её отрезком видео).  
Для `global` — один раз на все собранные сегменты сразу.

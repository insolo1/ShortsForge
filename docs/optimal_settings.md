# Оптимальные настройки

## Сколько ставить шортсов

Зависит от длительности видео и режима отбора:

### Режим `off` (простая нарезка)

```
shorts_count × short_length ≤ duration
примерно: short_length=45с → shorts_count = duration // 45
```

Если шортсов слишком много — они будут очень короткими. Нормально ставить столько, чтобы покрыть ~60-80% видео.

### Режим `parts` (сетка)

Лучший результат при `shorts_count ≈ 10–50`:
```
5 мин видео → 10 шортсов по 30с   (отлично)
1 час видео → 30-50 шортсов       (хорошо)
7 часов видео → 50-100 шортсов    (оптимально)
```

Сетка гарантирует равномерное покрытие, поэтому чем больше шортсов — тем больше разных участков видео будет показано. Но каждый шортс — локальный лучший, а не глобальный.

### Режим `hybrid` (гибрид) — рекомендуется

Оптимальное количество:
```
5 мин видео   → 10-15 шортсов
30 мин видео  → 20-30 шортсов
1 час видео   → 30-50 шортсов
7 часов видео → 100-150 шортсов
```

Формула: `shorts_count ≈ duration / (short_length × 3)`

**Для 7ч (25200с), short_length=59с:**
- 100 шортсов — хорошее покрытие, ~40% видео используется
- 150 шортсов — отличное покрытие, ~60% видео используется (рекомендуется)
- 200+ шортсов — избыточно, части станут слишком маленькими

### Режим `global` (топ)

Качество не зависит от количества — топ-N всегда лучшие:
```
shorts_count = 5-20
```
Больше 20 не имеет смысла — все лучшие моменты наберутся в первых 20 позициях, остальные будут значительно хуже.

## Длина шортса (short_length)

По стандарту YouTube Shorts: **макс 60 секунд**.

| Длина | Для чего |
|-------|----------|
| 15-30с | Быстрые, динамичные (мемы, реакции, тикток-формат) |
| 30-45с | Стандартные (рекомендуется, универсально) |
| 45-60с | Полноценные (обзоры, лайфхаки, образовательные) |

**Рекомендуется 45-59с** — YouTube не ограничивает показ, контент вмещается достаточно.

---

## Режим смарт-отбора

| Ситуация | Режим |
|----------|-------|
| Короткое видео < 5 мин | `off` или `global` |
| Лекция / интервью / стрим | `hybrid` (равномерно + качественно) |
| Обзор / топ / нарезка лучшего | `global` (только хиты) |
| Длинное видео > 2ч | `hybrid` (обязательно, включает InterestNet) |
| Тестовый прогон | `off` (быстро) |

## Примеры для разных видео

| Видео | short_length | shorts_count | Режим |
|-------|-------------|-------------|-------|
| 10 мин обзор | 45с | 10 | hybrid |
| 30 мин лекция | 59с | 25 | hybrid |
| 1 час интервью | 59с | 40 | hybrid |
| 3 часа стрим | 45с | 80 | hybrid |
| 7 часов курс | 59с | 150 | hybrid |
| 10 мин мем合集 | 30с | 15 | global |

## Производительность

Узкое место — Whisper-транскрипция:
```
1 час видео → ~3-5 мин транскрипции (CPU)
             → ~1-2 мин (GPU)

ffmpeg аудио + кадры (только для InterestNet): +10-30с
```

Скоринг и отбор: < 0.1с на любое видео.

# Video to Shorts Bot - Спецификация

## Обзор проекта
Веб-приложение для автоматического создания YouTube Shorts из длинных видео.

## Технологический стек
- **Backend**: Python + FastAPI
- **Frontend**: Простой HTML + TailwindCSS
- **Видео обработка**: FFmpeg, yt-dlp
- **AI**: OpenAI GPT-4 для генерации названий/тегов
- **STT**: Whisper для распознавания речи

## Функциональность

### 1. Загрузка видео
- Ввод URL с YouTube
- Загрузка локальных файлов (MP4, MOV, AVI)
- Прогресс загрузки

### 2. Нарезание на шорты
- Автоматическое определение сцен/моментов (через анализ аудио)
- Длина шортов: 30-60 сек (настраивается)
- Сохранение вертикального формата (9:16)
- Разрешение: 1080x1920

### 3. Анализ
- Распознавание речи (Whisper)
- Извлечение ключевых фраз
- Определение темы видео

### 4. Генерация
- Название для шорта
- Описание
- Теги (5-10 штук)
- AI предложения на основе контента

### 5. Результат
- Список созданных шортов
- Превью для каждого
- Скачивание архивом
- Редактирование названия/тегов перед скачиванием

## UI/UX

### Страница - Главная
- Header с названием
- Секция загрузки (URL или файл)
- Настройки (длина шортов, кол-во)
- Кнопка "Создать шорты"
- Список результатов с превью

### Дизайн
- Темная тема
- Минималистичный
- Карточки для шортов с превью
- Кнопки действий

## API Endpoints

```
POST /api/upload-url - Загрузка по URL
POST /api/upload-file - Загрузка файла
POST /api/process - Запуск обработки
GET /api/status/{job_id} - Статус обработки
GET /api/result/{job_id} - Результат
POST /api/update-shorts/{id} - Обновить метаданные
DELETE /api/delete/{job_id} - Удалить
```
